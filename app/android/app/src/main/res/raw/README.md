# Android RAW Audio Resources

Place athan audio files here for background notification sounds:
- `athan_makkah.mp3`
- `athan_afasi.mp3`
- `athan_sudais.mp3`
- `athan_madinah.mp3`
- `athan_fajr.mp3`
- `athan_turkey.mp3`
- `athan_ali_mulla.mp3`
- `notification_reminder.mp3`

These are used by Capacitor LocalNotifications as the channel sound.
The notification system will play these files as the athan sound even when the app is closed.
